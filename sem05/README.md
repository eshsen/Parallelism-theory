# YOLOv8s-pose — параллельный инференс на CPU

## Использование

### 1. Однопоточная обработка видео

```bash
python main.py --video_path input.mp4 --mode single --output out_single.mp4
```

### 2. Многопоточная обработка (4 потока)

```bash
python main.py --video_path input.mp4 --mode multi --output out_multi.mp4 --workers 4
```

### 3. Подбор оптимального числа потоков (бенчмарк)

```bash
python benchmark.py --video_path input.mp4 --max_workers 8
```

### 4. Real-time с камеры

```bash
python realtime.py --workers 4 --camera 0
# С записью результата:
python realtime.py --workers 4 --camera 0 --output cam_result.mp4
```

Нажмите `q` для выхода.

### 4. Вывод

В ходе лабораторной работы была исследована обработка видео с помощью модели YOLOv8s-pose с использованием разного количества потоков. Для этого измерялось время выполнения программы при 1, 2, 3, 4, 5, 6, 7 и 8 потоках, после чего строились графики ускорения и эффективности. 

По результатам эксперимента было установлено, что увеличение количества потоков практически не ускоряет работу программы. При однопоточном выполнении время обработки составило 36.21 с. Максимальное ускорение 1.09x было достигнуто при 3, 4 и 5 потоках, при этом наименьшее время обработки — 33.15 с — зафиксировано при 5 потоках. Однако эффективность при этом составила лишь 22%, что свидетельствует о нерациональном использовании вычислительных ресурсов. При дальнейшем увеличении числа потоков сверх пяти время выполнения незначительно возрастало.  

Таким образом, для данной задачи наиболее рациональным можно считать использование одного потока: дополнительные потоки создают избыточную нагрузку на систему при минимальном приросте производительности.
