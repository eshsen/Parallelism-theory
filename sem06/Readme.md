# Лабораторная работа №6 — Уравнение теплопроводности (2D, OpenACC)  

## 1. Цель работы  
Реализовать решение двумерного уравнения теплопроводности методом Якоби (разностная схема, пятиточечный шаблон) на равномерных сетках различного размера. Перенести программу на GPU с помощью директив OpenACC, 
произвести профилирование и оптимизацию. Сравнить производительность CPU (one-core, multicore) и GPU.  

- **Размеры сеток**: `128×128`, `256×256`, `512×512`, `1024×1024`
- **Граничные условия**: линейная интерполяция по краям между угловыми значениями
- **Значения в углах**:
  - `(0,0)` → 10
  - `(N-1,0)` → 20
  - `(0,N-1)` → 20
  - `(N-1,N-1)` → 30
- **Внутренняя область** изначально заполнена нулями
- **Тип данных**: `double`
- **Критерии остановки**:
  - Максимальная ошибка < `1e-6`
  - Максимальное число итераций = `1 000 000`
